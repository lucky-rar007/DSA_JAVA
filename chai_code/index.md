# ArraysAndHashing

1. ContainsDuplicate — HashSet to check whether any number appears more than once.
2. TwoSum — HashMap to store seen values and find the matching complement quickly.
3. GroupAnagrams — HashMap with normalized/sorted strings to group same-anagram words together.
4. TopKFrequentElements — Frequency map + heap to keep the k most frequent elements.
5. ValidAnagram — Frequency counting or sorting to compare character distribution between strings.

# Two Pointers

1. ValidTriangleNumber — Sort and use two pointers to count all valid triplets.
2. ValidPalindrome — Move pointers inward while ignoring non-alphanumeric characters.
3. TwoSumII — Start from both ends and shrink the search range to find the target pair.
4. TrappingRainWater — Use left/right max arrays with two pointers to calculate trapped water.
5. ThreeSum — Sort the array and use two pointers to find all unique triplets summing to zero.
6. SortColors — Dutch National Flag approach using a three-pointer partitioning strategy.
7. MoveZeroes — Maintain a slow pointer for non-zero values and push zeros to the end.
8. ContainerWithMostWater — Move the shorter side inward to maximize the area between two heights.
